## Opis loga
- Motiv: zlatne zrake sunca (svjetlo/aureola) iza obrisa usnulog lika (sv. Josip spavač) koji leži preko slova "FIDE"; obris je izveden jednom debelom linijom (glava lijevo, tijelo se spušta udesno do slova E).
- Kuća: tanki obris kuće s dvostrešnim krovom koji uokviruje "LIS" i "automatika"; lijevi zid kuće ujedno je slovo L.
- Tipografija: geometrijski sans-serif (u stilu Futura/Century Gothic), "FIDELIS" verzal, "automatika" tanko, malim slovima.
- Boje: tamnoplava #425C7A (FIDE + lik), sivoplava #7889A3 (LIS, kuća, automatika), zlatni gradijent oko #C3932E do svijetložute (zrake).
