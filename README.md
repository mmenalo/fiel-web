# Fiel d.o.o. — web stranica

Statična dvojezična (HR/EN) web stranica za Fiel d.o.o. — pametne kuće, video nadzor i IP portafoni.

- `index.html` — hrvatska verzija
- `en/index.html` — engleska verzija
- `pravila-privatnosti.html`, `en/privacy.html` — pravila privatnosti
- `assets/css/style.css`, `assets/js/main.js` — stil i skripte (bez build koraka)

Objavljuje se preko GitHub Pagesa iz grane `main`. Za lokalni pregled: `python3 -m http.server` u ovom direktoriju.
